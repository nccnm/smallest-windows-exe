# Two small Windows x64 tools in C without the CRT

The code in this folder is a personal proof of concept, not a full-featured copy of the two original applications ([Pulsar](https://github.com/oMaN-Rod/Pulsar) and [Wireless Device Battery Monitor](https://github.com/krisgfx9/Wireless-Device-Battery-Monitor)). It was written from scratch in C; no code was copied from either project.

## Run

```powershell
.\out\pulsar-mini.exe
.\out\battery-mini.exe
.\out\battery-mini.exe --list
.\out\battery-list.exe --list
```

- Pulsar mini: estimates CPU % from total idle time, plus RAM % and upload/download speed. The idle reading path was checked on Windows 11 build 26300 and shows `CPU --` when the query fails.
- Battery mini reads the battery through a Logitech `046D:C547` receiver, HID++ 2.0, polling every 60 seconds on its own worker. The slot 1 ping waits up to 1,500 ms for late replies.
- `battery-mini.exe --list` and Battery list: same driver, run once, write UTF-8 to stdout, exit code 0 when the battery was read or 1 when unavailable. `--list` is handled before the single-instance lock, so it can be called while the widget is running. The GUI uses a different HID++ software ID from the CLI.
- Right-click the widget to exit. Each kind runs only one instance; a second instance returns exit code 2.
- The two minis place themselves to the left of the system tray. The default is meant to replace the original applications; they do not avoid every other vendor's widget.

## Build

Needs MSVC x64 and the Windows SDK already installed. This script does not install any compiler.

```powershell
pwsh -NoProfile -File .\build.ps1
pwsh -NoProfile -File .\build.ps1 -Standard
pwsh -NoProfile -File .\build.ps1 -Target Pulsar    # the command typed in the video
```

The `vcvars64.bat` path points to Visual Studio 18 Community. Change that variable if your installation is elsewhere.

| Option | Meaning |
|---|---|
| `-Standard` | Default alignment, DYNAMICBASE/FIXED:NO, no byte-saving section merges |
| `-FullUI` | Adds the position menu and the `--preview` mode; avoids known original widgets |
| `-Diagnostics` | Builds `-p1.exe`, which logs taskbar/DPI/theme/power events and a heartbeat to `raw/p1-pulsar.md` or `raw/p1-battery.md` (relative to the working directory) |
| `-Static -Target Pulsar` | Static-text build used as the P1 baseline, reads no metrics |
| `-Target Pulsar` or `-Target Battery` | Builds only the selected group |
| `-Clang` | Uses clang-cl from MSYS2, output names get a `-clang` suffix |
| `-NetTable` | Variant that takes one snapshot of the legacy network table per tick instead of one call per interface |
| `-DiskGpu` | Builds the optional `pulsar-mini-disk-gpu.exe` with the highest busy level per disk and per GPU engine. Run one Pulsar build at a time |

Without `-FullUI`, `--preview` is not a feature of the minimal binary. To see the preview, build `-FullUI` and run the file with the `-full.exe` suffix with `--preview`.

The small build uses `/ALIGN:16 /FILEALIGN:16`, drops ASLR/relocations and uses an RWX code section. The 72-byte DOS stub generated by the script contains a DOS exit instruction; it does not affect the Win32 display. LINK emits warning LNK4108. These builds were only measured on Windows 11 build 26300; they are not certified for other builds. Both the small and the standard build keep `/GS` off; do not call the standard build "all mitigations on".

## Design and limits

- One hidden owner window receives `TaskbarCreated`, one child window sits on the taskbar, and one 1-second application timer drives updates. When Explorer destroys the child, the host stays alive and tries to create it again.
- CPU/RAM are sampled every second. The network is sampled about every 1 second when total traffic is above 16,000 B/s and about every 5 seconds below that; speed is divided by the real time between two samples. It can take up to about 5 seconds to notice new traffic after a quiet period. The layout is checked every 5 seconds, and DPI and theme changes are handled. It only draws when the text changes.
- No UI Automation is used to look for free space. The minimal build does not change its caption every second and does not provide an accessibility object through `WM_GETOBJECT`. This is an accessibility trade-off to keep in mind if you use a screen reader.
- The blocking wait only asks for the event types the widget needs; it does not call `Sleep(1)`, `timeBeginPeriod`, trim the Working Set or change Defender settings.
- Network: at most 8 active hardware interfaces, the list is refreshed about every 30 seconds. Tunnel/loopback are not added. Uses unsigned 32-bit deltas of the legacy counters; the test machine has 1 Gbps Ethernet. Not meant for 10 Gbps and up or for several wraps between samples. After a gap of 10 seconds or more, the delta is dropped so no fake speed is produced.
- The NetTable variant uses a 64 KiB buffer. If the interfaces do not fit, it shows unavailable instead of reading outside the buffer.
- A counter reset between two samples without an observed down state can cause one jumping speed sample; quick driver resets/toggles have not been tested. Do not use this PoC as a traffic counter for billing.
- Battery: only the receiver named above; no Bluetooth, Xbox, other vendors' drivers or HID++ 1.0. A timeout is never shown as 0%. Old data is marked stale and expires after 30 minutes.
- The `-DiskGpu` build samples disk/GPU on a PDH worker and keeps the default build as the P2 baseline. When there is no useful number it shows `--`. The test build was 10,912 B and one ETW run measured 5.133 wakeups/s. It was compared with Task Manager for a full 70 seconds with a maximum difference of 1 percentage point.
- No temperature, ping, autostart, self-update, saved settings or pause on lock/screen off.
- Pulsar v1.3 uses a 1,000 ms waitable timer and GetDC when the text changes. It still handles WM_PAINT when Windows asks for it.

## Measure

`-Diagnostics` is for P1 regression runs. Measure RAM and ETW with the default build.

Run each file one after another, so that a test instance does not keep holding the mutex.

```powershell
pwsh -NoProfile -File ..\tools\measure-resident.ps1 `
  -Exe .\out\pulsar-mini.exe -Settle 35 -Window 60 `
  -Label pulsar-mini-v13-repeat-run1 -Out .\out\pulsar-mini.jsonl
```
